    Frequently Asked Questions

    How do I export my data from Instagram? ▼
    Is my data safe? Do you store it? ▼
    Absolutely. InstaScope runs entirely in your browser — no data is ever sent to any server. Your ZIP file is read locally on your device. When you close the page, everything is gone. We never see, collect or store any of your Instagram data.
    Why does InstaScope show different numbers than Instagram? ▼
    There are a few common reasons for discrepancies. See the Troubleshooting section below for a detailed explanation of each possible cause and how to fix it.
    Can I use InstaScope on mobile? ▼
    Yes! InstaScope is fully responsive and works on any device — phone, tablet or desktop. Just download your Instagram export on your phone and upload the ZIP file directly from there.
    How do I use the History comparison feature? ▼
    Request two data exports from Instagram at different times (e.g. today and in a month). Then go to the History tab, upload the older ZIP as "Old File" and the newer one as "Current File", and click Compare. InstaScope will show you exactly who followed or unfollowed you in that period.
    Why does it say "0 following" after I upload? ▼
    This usually happens when you export data in HTML format instead of JSON. Make sure to select JSON when requesting your export from Instagram. Also ensure the date range is set to "All time", otherwise older following data may be missing.

    ⚠️ Troubleshooting — Why numbers may not match

    If the counts shown by InstaScope differ from what you see on Instagram, here are all the possible reasons and what to do about each one.

    📄

    Wrong export format (HTML instead of JSON)

    Most common cause

    Instagram lets you export in HTML or JSON. InstaScope only reads JSON format. If you see 0 users or very few results, you likely exported in the wrong format.

    • Go back to Instagram and request a new export
    • When selecting format, choose JSON (not HTML)
    • Set the date range to "All time"
    📅

    Date range not set to "All time"

    If you set a limited date range during export (e.g. "Last 30 days"), Instagram will only include accounts you started following or who started following you within that period — not your full list.

    • Request a new export and set the date range to "All time"
    ⏳

    Export data is not up to date

    Instagram exports are a snapshot in time. If someone followed or unfollowed you after you requested the export, those changes won't be reflected. The export can also take several hours to be generated.

    • Request a fresh export if you need current data
    • Use the History tab to compare two exports and see changes
    👻

    Ghost or deactivated accounts

    Instagram's in-app follower count includes deactivated, deleted and suspended accounts. These accounts still appear in your follower count on Instagram but may not always appear in the JSON export, causing a small discrepancy.

    📦

    Uploaded the extracted folder instead of the ZIP file

    InstaScope needs the original .zip file, not the folder you get after extracting it. If you unzipped the file first, you uploaded the wrong thing.

    • Find the original .zip file (usually in your Downloads folder)
    • Upload that file directly — do not unzip it first
    🔢

    Instagram export split across multiple files

    If you follow or are followed by a large number of accounts, Instagram may split your follower data across multiple files (followers_1.json, followers_2.json, etc.). InstaScope automatically reads all of them from the ZIP, so this should not cause issues — but make sure you uploaded the complete ZIP and not a partial one.

    🔄

    Still seeing wrong numbers?

    Try this checklist:

    • Request a brand new export from Instagram
    • Select format: JSON
    • Date range: All time
    • Wait for the email from Instagram (can take up to a few hours)
    • Download and upload the original .zip file
    • Open browser DevTools (F12) → Console tab → check for any errors
